산행안전 양자 AI 에뮬레이팅 실험실 v03 작업을 이어서 함.

1. 먼저 프로젝트 문서 "claude/양자에뮬레이터_v03_작업인계_2026-11-12.md"를 project_read로 끝까지 읽을 것.
2. 내 PC 연결 폴더 D:\QP 를 확인하고(get_device_info, device_list_dir), 작업 원본은 D:\QP\versions\v03\web 임.
   수정은 가능하면 device_bash로 D:\QP에서 직접 하고, 클라우드에서 작업했다면 바뀐 파일을 새 폴더에 복사해 device_commit_files(force:true)로 저장할 것.
3. 수정 후에는 python tools\bundle.py v03 로 단일 HTML을 다시 만들고,
   claude.ai 게시본(slug 07449fc4-6ecc-42af-9e18-c5eb7b38eedd)에 get_artifact로 최신 version을 받아 publish_files로 index.html을 갱신할 것.
4. 인계 문서의 "2. 사용자 고정 선호"를 반드시 지킬 것(답변 ~함/~임, 질문은 존댓말, 가운뎃점 금지, 근거 기반, 음성 해설 ~입니다, 과 번호 숫자, 설명과 진행 속도 맞춤, 구분되는 천연색, 번호 붙이기, 요청마다 실제 적용 후 검증).
5. 이어서 할 일은 인계 문서 "4. 남은 일"부터 시작함. 우선순위:
   (1) 아래 "100대 명산 현재 실시간 산행 정보" 띠의 실시간 날씨가 내 PC(run.bat)에서 실제로 뜨는지 확인 방법을 알려 주고, 보기 어려우면 우측 화면 상단 빈 곳에 박스로 옮김
   (2) 100대 명산 전체 목록, 번호, 정상 좌표 확보 후 반영(근거 출처 명시)
   (3) 메타러너 성능 차이(메타 0.70 vs 무작위 0.60) 개선
   (4) 학습 과정, DNN, 메타러닝, 양자 동작 그래픽과 애니메이션 계속 보강

작업 전에 현재 상태를 짧게 요약해 보고하고, 무엇부터 할지 확인해 주기 바람.
