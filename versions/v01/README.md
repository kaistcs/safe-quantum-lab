# 산행안전 비교 실험실 01

이 폴더에는 웹 버전 01의 소스와 브라우저에서 사용하는 자료가 있습니다. 새 변경 버전은 다음 번호의 폴더에 저장합니다.

- dist/index.html은 화면 구성입니다.
- dist/style.css는 화면 디자인과 모바일 배치입니다.
- dist/scenarios.js는 가상 산행, 조절 가능한 신호 20개와 즉시 적용하는 안전 규칙입니다.
- dist/model.js는 양자 회로 에뮬레이션, AI 모델 학습, 검증과 시험입니다.
- dist/app.js는 재생, 입력 변경, 비교 화면과 한국어 음성입니다.

## 로컬 확인

이 폴더에서 `python -m http.server 8080 --directory dist`를 실행하고 브라우저에서 `http://localhost:8080`을 엽니다. 웹 버전의 비교에는 실제 GPS, 기상, 심박 또는 양자 하드웨어가 연결되지 않습니다. 한국어 동적 TTS는 브라우저가 제공하는 한국어 음성을 사용합니다.

## 비교 방식

세 방식 모두 같은 합성 입력과 정답을 사용합니다. 일반 AI는 원래 특징을 사용합니다. 양자 특징 AI는 두 큐비트의 RY와 CNOT 회로로 계산한 여섯 개의 결합 특징을 더합니다. 일반 수식 대조군은 같은 특징을 코사인 곱으로 계산합니다. 학습 대상은 세 모델의 로지스틱 회귀 가중치이며 회로는 고정합니다. 검증 정상 표본에서 약 10%의 오경보 예산으로 기준을 선택하고 별도 합성 시험 표본으로 결과를 집계합니다.
- dist/guide.js는 초보자를 위한 회전, 조건부 뒤집기, 확률과 메모리 계산을 보여 줍니다.

## 브라우저에서 바로 열기

같은 폴더의 산행안전_웹실험실_01.html에는 계산 코드와 사진, 예제 음성이 들어 있습니다. Windows 파일 탐색기에서 파일을 열면 로컬 서버 없이 사용할 수 있습니다. 웹 주소 배포는 별도의 게시가 필요합니다.
